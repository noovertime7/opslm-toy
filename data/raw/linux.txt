Linux 是一种广泛使用的开源操作系统。

Linux 内核负责进程调度、内存管理、文件系统、设备驱动和网络协议栈。

Linux 中的进程是正在运行的程序实例。

每个进程通常拥有一个唯一的进程 ID，也就是 PID。

ps 命令可以查看系统中的进程。

top 命令可以实时观察系统负载和进程资源使用情况。

htop 提供了更加直观的进程监控界面。

uptime 可以查看系统运行时间和平均负载。

load average 可以帮助判断系统当前的负载情况。

free 命令可以查看系统内存使用情况。

Linux 会使用空闲内存作为文件缓存。

因此不能简单根据 free 输出中的 used 数值判断系统是否缺少内存。

available 通常比 free 更适合判断当前还有多少可用内存。

vmstat 可以观察 CPU、内存、进程和 IO 等系统指标。

mpstat 可以查看 CPU 使用情况。

pidstat 可以观察不同进程的 CPU、内存和 IO 使用情况。

iostat 可以用于分析磁盘 IO 性能。

磁盘 IO 问题通常需要关注吞吐量、IOPS、延迟和队列长度。

df 命令用于查看文件系统的磁盘空间使用情况。

du 命令可以统计目录和文件占用的空间。

如果磁盘空间耗尽，应用程序可能无法继续写入日志或数据。

inode 耗尽也可能导致无法创建新的文件。

df -i 可以查看文件系统 inode 的使用情况。

Linux 中的文件权限通常由用户、用户组和其他用户三个部分组成。

chmod 可以修改文件权限。

chown 可以修改文件的所有者和所属用户组。

systemd 是现代 Linux 系统中常见的服务管理器。

systemctl status 可以查看服务状态。

systemctl start 可以启动服务。

systemctl stop 可以停止服务。

systemctl restart 可以重新启动服务。

journalctl 可以查看 systemd 管理服务产生的日志。

journalctl -u 可以查看指定服务的日志。

dmesg 可以查看内核日志。

Linux 中的 OOM Killer 会在系统严重缺少内存时终止部分进程。

如果容器或者进程因为内存不足被终止，应该进一步检查内存限制和实际内存使用情况。

kill 可以向进程发送信号。

SIGTERM 通常用于请求进程正常退出。

SIGKILL 会直接终止进程，进程无法捕获该信号。

使用 kill -9 之前应该确认普通终止方式是否无效。

lsof 可以查看进程打开的文件和网络连接。

ss 可以查看 TCP 和 UDP socket。

ip addr 可以查看网络接口和 IP 地址。

ip route 可以查看系统路由表。

ping 可以用于测试基本网络连通性。

traceroute 可以帮助观察网络路径。

curl 可以用于测试 HTTP 服务。

dig 可以用于查询 DNS。

nslookup 也可以进行 DNS 查询。

Linux 故障排查不应该一开始就重启服务器。

通常应该先收集当前状态、日志和监控指标，避免丢失重要现场信息。
